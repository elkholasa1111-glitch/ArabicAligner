# ArabicAligner — محاذاة النص العربي مع الصوت

[English](README.md) · [التنزيل](https://github.com/elkholasa1111-glitch/ArabicAligner/releases) · [نتائج الاختبارات](docs/VERIFICATION.md)

برنامج سطح مكتب يزامن **النص العربي الموجود عندك** مع تسجيله، ويخرج ملف SRT قابلًا للمراجعة في محرر ترجمة أو برنامج مونتاج. يستعين بتعرّف محلي على الكلام لتقدير التوقيت ثم يحتفظ بكلمات النص الأصلي وتشكيله. لا يترجم إلى لغة أخرى، ولا يضمن دقة كاملة. المسؤول عن الصيانة Mahmoud Hussein Attay Elsayed؛ حقوق كود التطبيق الأصلي Elkholasa. [مصدر النسختين ونسب العمل](docs/PROVENANCE.md).

## ابدأ من هنا

الإصدار العام الموحد الأول **1.2.0-beta.1 تجريبي**. افتح [Releases](https://github.com/elkholasa1111-glitch/ArabicAligner/releases) وحمّل ملف نظامك عندما يكون منشورًا بالفعل. عدم وجود ملف لنظام معين يعني أنه لم يُتح بعد. الملفات المصدرية المضغوطة ليست مثبتات.

| النظام | الملف | النماذج |
| --- | --- | --- |
| Windows x64 | `ArabicAligner_1.2.0-beta.1_Windows_x64_Setup.exe` | small السريع وlarge-v3-turbo |
| macOS Intel x86_64 | `ArabicAligner_1.2.0-beta.1_macOS_Intel.dmg` | small السريع فقط |

Windows غير موقّع بشهادة. تطبيق الماك بتوقيع محلي ad-hoc، دون Developer ID أو notarization. ليس universal ولم يُختبر Apple Silicon أو Linux أو Windows ARM. هدف البناء Windows 10/11 x64 وmacOS 13 فأحدث، لكن النسخ المختبرة فعلًا مسجلة في [التحقق](docs/VERIFICATION.md). الاختبار على Mac Intel حديث لا يثبت الأداء على MacBook Air 2015؛ يلزم تجربته على الجهاز نفسه.

1. قارن SHA-256 بملف `SHA256SUMS` الخاص بالنظام في الإصدار.
2. ثبّت Windows لحسابك؛ النسخة التجريبية منفصلة عن القديمة. على الماك افتح DMG وانسخ التطبيق إلى Applications، مع حفظ النسخة القديمة إن وجدت.
3. اختر ملف الصوت أو اسحبه، والصق نفس الكلام أو افتح ملف TXT بترميز UTF-8.
4. اختر النموذج واضغط **Align & Create SRT**. سيُحفظ SRT بجانب الصوت. استخدم **Open SRT** أو **Open Folder** أو **Save As** ثم راجع التوقيت بالسماع.

تدعم نافذة الاختيار WAV وMP3 وM4A وOGG وFLAC وMP4 وAAC وWMA؛ الدعم الفعلي يعتمد على فك الترميز ولا يشمل DRM. لا ندّعي اختبار كل صيغة. توجد [عينات أصلية قصيرة](examples/README.md) بالفصحى وبصياغة مصرية، بصوت اصطناعي عربي ليس معيارًا لدقة اللهجة المصرية.

## الحدود والخصوصية

النص المختلف عن الصوت أو الكلمات غير المنطوقة يحتفظ بها البرنامج ويقدّر توقيتها، وقد يخرج ملفًا صحيح الصيغة لكنه يحتاج تصحيحًا كبيرًا. نسبة low-conf إشارة داخلية للتطابق وليست قياسًا مستقلًا للدقة. الصمت، الموسيقى، التكرار وتداخل الكلام واللهجات تحتاج مراجعة. لا توجد خوارزمية CTC/MMS خارجية مدمجة.

لا يوجد إلغاء أثناء العمل حاليًا؛ يغلق البرنامج بعد انتهاء المعالجة. يمكن إعادة المحاولة بعد الخطأ. إذا فشل الحفظ بجانب الصوت، استخدم Save As. الحزم الكاملة تتضمن النماذج وتعمل محليًا دون حساب أو مفاتيح أو رفع صوت أو telemetry. تنزيل أدوات البناء والنماذج مطلوب عند تجهيز بيئة التطوير. السجلات المحلية قد تحتوي مسارات وأخطاء؛ راجعها قبل مشاركتها.
