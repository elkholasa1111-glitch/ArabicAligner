# Roadmap

1. Collect reproducible feedback on the Windows x86_64 and macOS x86_64 preview.
2. Improve diagnostics for unmatched text without presenting similarity as an
   independently calibrated timing-accuracy score.
3. Expand a legally redistributable Arabic evaluation corpus with independent
   reference timings and clearly identified dialects and recording conditions.
4. Investigate cancellation that can safely stop decoding/inference and clean
   temporary files. Cancellation is not currently implemented.
5. Consider Apple Silicon only after a native build and complete acceptance test.

These directions are not release dates or implemented features.
No cloud transcription, account system, telemetry, or paid service is planned as
a prerequisite for local use.
