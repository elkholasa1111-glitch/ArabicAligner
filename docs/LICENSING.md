# Source, licenses, and replacing shared components

Original application code is MIT, copyright 2026 Elkholasa, authorized by the rights holder through its maintainer. This license covers owned code and does not replace any upstream license. Short original example scripts and generated synthetic WAVs are separately dedicated under CC0 as described in examples/README.md. The old private speech sample was excluded because its redistribution provenance was not established.

Qt/PySide6 6.11.2 uses the LGPL option for the dynamically linked widget runtime. This application permits reverse engineering needed to debug modifications to LGPL components and imposes no additional EULA restriction. Windows libraries are loose files inside `_internal`; macOS libraries/frameworks are under Contents/Frameworks and resources under Contents/Resources. Keep an original copy, replace a library with a compatible build or rebuild the application from this source, and reapply only a local ad-hoc signature when needed on Mac. A replacement must match the ABI and architecture. No vendor signing key is required. Do not disable device security globally.

Release assets mirror exact QtBase, Qt for Python (including shiboken) and translation source archives listed in third_party/sources.lock.json. The package's actual upstream license and bundled-third-party texts are collected under licenses/. Qt sources include their build instructions; use Qt's documented configure/cmake build and PySide's setup tooling for the corresponding 6.11.2 version. The application build recipe is BUILDING.md. These archives preserve upstream notices and are provided alongside the binaries, not only as an offer requiring contact.

FFmpeg 8.1.3 is built from pinned source with --disable-gpl --disable-nonfree --enable-version3, no external codec libraries, shared libraries, no network support, and a restricted PCM/WAV output path. Its applicable library/executable license is LGPL-3.0-or-later for this configuration. PyAV 17.1.0 (BSD-3-Clause) is compiled against that same SDK. Actual linked library license/configuration is checked during frozen acceptance; record it in the verification report. Source archives, configure arguments and exact builder are supplied. Replace/rebuild compatible shared libraries or rebuild the application to use modified components. LGPL/GPL license texts included for LGPL references do not mean this build enabled GPL codecs.

Do not infer this configuration for old private installers. The older Windows Gyan FFmpeg and PyAV wheel had different configurations; the old Mac used a different media binary. They are not republished as this audited release.

Whisper model weights and converted snapshots retain their upstream MIT notices. Pinned repository/revision links are in LICENSES.md and the asset manifest. Runtime dependencies have distinct terms including Python PSF, NumPy BSD, tokenizers Apache-2.0, and native runtime notices. Build tools and eSpeak are not shipped as application runtime. Verify a new native dependency or plugin before adding it; do not label the whole installer MIT.

NumPy 1.26.4 is also built from pinned source for these releases. macOS links Apple system Accelerate (13.3+) and Windows uses the source distribution’s built-in numerical implementation. Neither controlled NumPy wheel ships OpenBLAS/libquadmath/libgfortran runtime binaries. The source archive and actual numerical build record accompany the release. Older upstream NumPy wheel runtime licensing is not assumed to describe these packages.

CTranslate2 4.8.2 uses its MIT source license plus preserved third-party notices (including Ruy/CPU features and Eigen). The controlled builds disable Intel MKL, Intel OpenMP, oneDNN and CUDA; CPU INT8 and threading remain enabled. The exact CPU source tree with pinned submodules is a release asset, including covered Eigen source. LLVM OpenMP on Mac retains its Apache/LLVM and legacy notices; standard Microsoft compiler runtimes on Windows retain Microsoft terms. Those runtimes are not described as MIT application code.
