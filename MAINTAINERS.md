The primary maintainer has confirmed responsibility for maintenance and administers this repository. **Elkholasa** holds the original application rights and authorized its MIT licensing. Dependencies retain their own rights and licenses.

## Change review

Use an issue for a reproducible problem or proposed behavior, and a pull request for a reviewable change. The maintainer decides what is merged and released. CODEOWNERS points to the same maintainer; it does not establish authorship of every file or imply an additional review team.

Changes should preserve Arabic reference words and diacritics, local processing, valid subtitle times, and documented platform differences. Contributions need appropriate validation and a clear origin for code and sample data. See [Contributing](CONTRIBUTING.md).
